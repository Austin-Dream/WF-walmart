# 沃尔玛订单处理工具集

本工具集包含两个独立的 Streamlit 应用，专为沃尔玛（Walmart）卖家设计，用于处理订单格式转换及批量填写物流追踪号。

## 工具列表

### 1. 赛狐文件和 WF 对接转化器
- **功能**：将赛狐平台导出的订单数据转换为 Wayfair 多渠道配送（WF）可导入的格式。
- **核心特性**：
  - 自动映射 SKU（WS007 系列按规则转换，WS008 系列保留原 SKU）。
  - 跨文件防重复：记录已处理的订单（订单号+SKU），避免重复发货。
  - 文件内合并：同一订单号+同一 SKU 自动累加数量。
  - 自动拆分地址、格式化电话号码。
  - 输出文件包含日期行，007/008 订单分区域显示。
- **输入**：赛狐导出的 Excel 文件（需包含订单号、SKU、数量、收货人、地址等字段）。
- **输出**：符合 Wayfair 多渠道格式的 Excel 文件。

### 2. 沃尔玛批量填写追踪号
- **功能**：根据已发货订单的追踪信息，自动批量填写到未发货订单表格中。
- **核心特性**：
  - 灵活匹配订单号列（支持自定义列名）。
  - 支持更新追踪号、承运商、追踪链接。
  - 预览匹配结果，避免误填。
- **输入**：
  - 待更新文件（未发货订单表）。
  - 已发货文件（包含订单号及对应的追踪号）。
- **输出**：更新后的 Excel 文件，可直接用于沃尔玛批量上传单号。
